# Dar de alta un cliente
Antes de crear un cliente, buscalo por nombre o CUIT para no duplicarlo.

## Pasos
1. Abrí Contactos, o Ventas y luego Clientes.
2. Hacé clic en Nuevo.
3. Elegí si es empresa o persona.
4. Completá razón social, CUIT, condición frente al IVA, dirección y correo de facturación.
5. Guardá.

## Datos obligatorios
Sin CUIT y condición frente al IVA no se puede facturar. Si el cliente es del exterior, avisá a Administración.
