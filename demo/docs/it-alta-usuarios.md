# Alta de un usuario nuevo
Este procedimiento es interno del equipo de IT.

## Pasos
1. Crear la cuenta de Google Workspace en la unidad organizativa del área.
2. Crear el usuario de Odoo y asignar los grupos de acceso según el puesto.
3. Agregar a la persona a las unidades compartidas que correspondan.
4. Enviar las credenciales iniciales por el canal seguro acordado.
